# 交互与行为

返回入口：[agent.md](../agent.md)

## 输入映射

手势识别在 `src/app/Input.ts`：拖动超过 6 px 算拖拽，两次点击间隔小于 0.33 s 算双击。命中判定和响应在 `App.ts` 的 `pick` / `onDragStart` / `onRelease` / `onKey`，命中顺序是 雨伞 → 小球 → 地面 → 天空。

| 操作 | 结果 |
|---|---|
| 悬停小球 | 开心表情，来回移动光标会“撸”它（`addPet`） |
| 单击小球 | 戳一下：表面凹陷、弹跳（`boop`） |
| 双击小球 | 空翻（`flip`） |
| 拖拽小球 | 抓起、甩出，松手后自己滚回原位（`startGrab` / `endGrab`） |
| 单击地面 | 小球走过去，地面按天气溅雪 / 溅水 / 扬尘，并产生涟漪 |
| 单击雨伞 | 伞转起来，甩出一圈水珠 |
| 拖拽天空 | 白天移动太阳（`Weather.sunOverride`，换天气时恢复），夜里移动月亮（`TimeOfDay.moonOverride`） |
| 1–6 | 切换天气 |
| N / 天气弹层的“时间” | 白天 ↔ 夜晚；弹层里还可以选“自动”（跟随本机时间，默认） |
| 空格 | 跳 |
| 方向键 | 推着小球滚动 |
| 光标移动 | 镜头轻微视差，小球目光跟随 |

## 小球行为 `src/characters/ball/BallBrain.ts`

- **表情**：由计时器和环境混合而成。晴天看太阳会眯眼，大风持续眯眼，30 秒无操作会睡着（`zzz…`），落地太重会晕。
- **目光**：随机看镜头、标题，或看与天气相关的东西（晴天看太阳、雨天看伞、雪天看雪花、大风看来风方向）。
- **事件**：Brain 只往 `events` 里发事件，由 App 统一处理音效、粒子和气泡文字：`boop`、`flip`、`grab`、`hop`、`land`、`shed`、`release`、`say`。
- **气泡文字**：通过 `say(text, dur)` 发出，例如甩出时“哇啊——”、摔晕时“晕…”。

## 天气与小球的互动

| 天气 | 互动 |
|---|---|
| 雨 | 自动撑伞（`UmbrellaRig`，弹簧式弹开，随风摆动）；雨滴打在伞面溅起水花，伞面有水珠和落点涟漪；雨水从八根伞骨尖连续滴落，落地溅水并在伞边一圈激起涟漪；伞下的球淋湿得少，地面伞下留出干燥区；球身有水珠 |
| 雨 → 大风 | 伞被吹飞（“我的伞！”） |
| 雪 | 球顶逐渐积雪，跳跃或翻转时把雪甩掉（`shed`）；落地、滚动在雪地压出雪坑 |
| 大风 | 阵风超过静摩擦时把球推向下风；飞沙打在球上；地面流沙 |
| 雾 | 光标和小球能拨开近处低雾（`InteractionMap` 的 alpha 通道） |
| 晴 | 太阳照出投影和接触阴影；可以拖拽天空移动太阳 |

地面上的涟漪、雪坑、拨雾都写进 `src/world/InteractionMap.ts` 的一张跟随小球的 GPU 贴图，地面和雾的 shader 再读取它。

## 扩展建议

- 新增一种交互：在 `App.pick` 里加命中目标，在 `onRelease` 里分发，具体行为写进 Brain，通过事件把效果（音效、粒子）交回 App。
- 新增事件类型：扩展 `BallEvent` 联合类型，然后在 `App` 的事件 switch 里处理。
- 粒子效果在 `ParticleSystem` 里加类型（`PT`），渲染分支在 `ParticleRenderer` 的片元着色器里加。
